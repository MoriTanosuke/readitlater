    Export und Import

    Export

    Lädt alle deine Artikel als eine Datei herunter: Adresse, Titel, Volltext, Schlagwörter, Gelesen-Status und Speicherdatum. Die Datei enthält nur deine eigenen Daten. Du brauchst dafür kein weiteres Programm, der Browser speichert sie wie jeden anderen Download.

    Alle Artikel herunterladen

    Import

    Spielt eine Datei ein, die diese App exportiert hat. Artikel mit einer Adresse, die du schon gespeichert hast, bleiben unverändert. Beim Import werden keine Seiten aus dem Internet geladen, und der Text wird noch einmal bereinigt.

    Teilen aus anderen Apps

    Mit einem Token speicherst du Artikel direkt aus dem Teilen-Menü deines Android-Geräts (HTTP Shortcuts) oder deines iPads (Kurzbefehle). Ein Token darf nur Artikel hinzufügen, nichts lesen oder löschen. Du kannst es jederzeit widerrufen.

      Einrichtung

      Adresse der Schnittstelle:

      Sende eine POST-Anfrage mit dem Header Authorization: Bearer <Token> und der Adresse des Artikels entweder als Text oder als JSON {"url": "https://…"}. Auch ein Freitext wie „Titel https://…“ funktioniert, es zählt die erste Web-Adresse darin.

      Android: HTTP Shortcuts
      1. Neuen Shortcut anlegen, Methode POST, URL wie oben.
      2. Header Authorization mit dem Wert Bearer und deinem Token.
      3. Anfragetext: „Benutzerdefinierter Text“ mit der Variable für den geteilten Text, Typ text/plain.
      4. Die Variable so einstellen, dass sie den Wert aus dem Teilen-Dialog übernimmt, und den Shortcut für das Teilen-Menü freigeben.
      iPad und iPhone: Kurzbefehle
      1. Neuen Kurzbefehl anlegen, in den Details „Im Share Sheet anzeigen“ einschalten, Eingabe: URLs und Text.
      2. Aktion „Inhalte von URL abrufen“: URL wie oben, Methode POST.
      3. Header Authorization mit Bearer und deinem Token.
      4. Anfragetext: „Datei“ bzw. Text mit der Variable „Kurzbefehleingabe“.
